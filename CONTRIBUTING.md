# Contributing to AuraBeats

First off, thank you for considering contributing to AuraBeats! 🎉

---

## 📜 Code of Conduct

Be respectful, inclusive, and professional. Harassment or abusive behavior will not be tolerated.

---

## 🐛 How to Report Bugs

1. **Check** if the bug has already been reported in [Issues](https://github.com/SakilSakil699/AuraBeats/issues)
2. **Open a new issue** with:

   - Clear title
   - Detailed description
   - Steps to reproduce
   - Expected vs actual behavior
   - Screenshots (if applicable)
   - Your environment (OS, Python version, etc.)

---

## 💡 How to Suggest Features

1. **Check** [Discussions](https://github.com/SakilSakil699/AuraBeats/discussions)
2. **Open an issue** with label `enhancement`
3. Explain:

   - Why the feature is useful
   - How it should work
   - Any alternative approaches

---

## 🔧 How to Contribute Code

### 1. Fork the Repository

Click **Fork** button on GitHub.

### 2. Clone Your Fork

    git clone https://github.com/YOUR_USERNAME/AuraBeats.git
    cd AuraBeats

### 3. Create a Branch

    git checkout -b feature/your-feature-name

### 4. Install Dev Dependencies

    python3.12 -m venv venv
    source venv/bin/activate
    pip install -r requirements.txt
    pip install -r requirements-dev.txt

### 5. Make Your Changes

- Follow **PEP 8** style guide
- Add docstrings to functions
- Keep commits small and focused
- Don't remove or modify credit notices

### 6. Test Your Changes

    make test      # Run tests
    make lint      # Check code style
    make format    # Auto-format code

### 7. Commit Your Changes

    git add .
    git commit -m "feat: add your feature description"

**Commit message format:**

| Prefix | Meaning |
|--------|---------|
| `feat:` | new feature |
| `fix:` | bug fix |
| `docs:` | documentation |
| `style:` | formatting |
| `refactor:` | code refactoring |
| `test:` | testing |
| `chore:` | maintenance |

### 8. Push to Your Fork

    git push origin feature/your-feature-name

### 9. Open a Pull Request

- Go to your fork on GitHub
- Click **Compare & pull request**
- Fill in the PR template
- Wait for review

---

## 🛡️ Credit Protection Rules

**AuraBeats has built-in anti-copy protection.**

**DO NOT:**

- ❌ Remove or modify credit notices
- ❌ Delete watermark lines
- ❌ Change author information
- ❌ Bypass integrity checks

**Doing so will:**

- Break the bot at startup
- Violate the license terms
- Get your PR rejected
