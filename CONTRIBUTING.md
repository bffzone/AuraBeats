# Contributing to AuraBeats

First off, thank you for considering contributing to AuraBeats! 🎉

---

## 📜 Code of Conduct

Be respectful, inclusive, and professional. Harassment or abusive behavior will not be tolerated.

---

## 🐛 How to Report Bugs

1. **Check** if the bug has already been reported in [Issues](https://github.com/SakilSakil699/AuraBeats/issues)
2. **Open a new issue** with:
   - Clear title
   - Detailed description
   - Steps to reproduce
   - Expected vs actual behavior
   - Screenshots (if applicable)
   - Your environment (OS, Python version, etc.)

---

## 💡 How to Suggest Features

1. **Check** [Discussions](https://github.com/SakilSakil699/AuraBeats/discussions)
2. **Open an issue** with label `enhancement`
3. Explain:
   - Why the feature is useful
   - How it should work
   - Any alternative approaches

---
