## [1.0.0] - 2026-10-14

### 🎉 Initial Release

#### Added
- 🎵 Core music streaming (YouTube)
- 🎛️ 7 audio filters (Bass, Treble, Nightcore, Vaporwave, 8D, Karaoke, Reverb)
- 📋 Queue management (add, shuffle, loop, clear)
- 🎨 Live progress bar (updates every 10 seconds)
- 🖼️ Thumbnail support
- 💎 Download songs (MP3/MP4 via DM)
- 🔗 Clickable song links
- ⚙️ User settings (language, quality)
- 🌍 Multi-language (English, Hindi, Urdu, Arabic)
- 🛡️ Credits protection (anti-copy)
- 🤖 Auto-join assistant
- 📊 Admin panel
- 🐳 Docker support
- 🚀 Makefile for easy commands
